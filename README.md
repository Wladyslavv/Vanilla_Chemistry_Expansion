# 卡特尔扩展 / Cartel Expansion

**[English version](README_en.md)** · 整个 mod 的完整玩家说明见 [docs/MOD_GUIDE.md](docs/MOD_GUIDE.md) · 规划中的抗生素与菌种选育系统设计见 [docs/ANTIBIOTICS_DESIGN.md](docs/ANTIBIOTICS_DESIGN.md)

《原版化学扩展》（Vanilla Chemistry Expansion，Probably Stolen 模组）的卡特尔系统。它在原版化学家开局的卡特尔之外，新增了一个所有开局都能接触到的**卡特尔网络**：加入它、被它抵制、或者帮治安部把它连根拔起。

> **默认关闭。**在 mod 设置 → "卡特尔 / Cartel" → **启用卡特尔扩展** 中打开。关闭时本页所有内容都不生效（已加入的存档仍会在声望面板显示"卡特尔网络"一栏，但不会触发任何效果）。原版化学家开局的卡特尔始终是原版逻辑，不受影响。

## 加入卡特尔网络

卡特尔网络是一个新阵营，加入后出现在原版声望面板中，存档、提示、声望涨跌都沿用原版机制。

### 化学家开局
完成原版卡特尔的"获准退出"后，自动加入卡特尔网络，**初始声望 50**：

> 你和卡特尔的债终于勾销了。现在，卡特尔希望与你合作，而决定的权力可能不单单在你们任何一方的手上。

在本扩展之前就已经退出的老存档，下次读档时加入。

### 其他开局

**1. 被注意到。**每卖出一件**违禁品**且带**医疗品**或**麻醉品**标签的商品，成交价计入累计金额。

**2. 字条。**累计满 **500** 后，第二天起床时，**里柜台**正中（满了就放外柜台）会出现一只封着黑蜡、压着眼睛印记的信封。打开是一张对折的旧纸，墨迹画着一只淌墨的眼睛：

> 我们看见

**3. 接头人。**累计满 **1000**，且字条已在之前某天送达（一次卖出很多也会先收到字条），**卡特尔接头人**开始上门，直到玩家给出答复：

> 希望我们上次相遇没吓到你。
> 我们关注了你很久了。
> 没有人可以在卡特尔眼底下悄无声息地出货。
> 现在，你最好交一笔保护费，我们未来可以允许你成为我们的合作伙伴。
> 拒绝不是一个选项。

| 选项 | 结果 |
|---|---|
| **[支付100信用点加入卡特尔网络]** | 加入，初始声望 **0**；现金不足时不可选 |
| **[请他两天后再来]** | 两天后再来，届时不再提供此选项 |
| **[拒绝卡特尔]** | "哈哈，真幽默。""没有活人能拒绝卡特尔。"——进入[拒绝的后果](#拒绝卡特尔的后果) |

## 拒绝卡特尔的后果

### 拒收
拒绝后，每位客人在你**第一次**把违禁品或赃物摆到他面前时判定一次：**33%** 的客人整次来访都拒收违禁品和赃物，并说：

> 不好意思，但是我们不能从你这进货。

治安部客人、以及原版本来就不收违禁品的客人（部分拾荒者和下层区市民）卡特尔管不着，不参与判定。

### 接头人再访
拒收累计满 **10** 次后的第二天，接头人再次上门（已获得"对抗卡特尔"标签则不会再来）：

> 我想某人一定学到了教训。
> 但是生活中有些教训只有一次。

| 选项 | 结果 |
|---|---|
| **[支付200信用点加入卡特尔]** | "欢迎入伙。（冷笑）"——加入，初始声望 0，拒收停止 |
| **[拒绝卡特尔]** | 直接离开，记录第二次拒绝 |

## 对抗卡特尔：治安部路线

### 触发条件（每晚检查）
1. 至少被拒收过一次；
2. 治安部声望 ≥ 80；
3. 以下任一：曾向治安部或上层区出售失能剂；或 上层区声望 + 治安部声望 −（下层区声望 + 革命军声望 + 黑市声望）≥ 50；或 下层区、革命军、黑市任一声望为负；
4. 不是卡特尔网络成员。

### 治安部警员
条件第一次满足的第二天上门；此外，第二次拒绝卡特尔时若条件满足且尚未举报，三天后再来一次。

> 公民，最近我们发现附近有卡特尔活动。如有任何可疑行为，请上报。

- **[举报卡特尔]**："很好，治安部已决定在近期对本地非法组织进行一次集中搜捕。""任何热心公民的……自愿捐赠……都非常受鼓励。"——获得 **对抗卡特尔** 标签。
- **[不举报卡特尔]**：结束对话（第二次拒绝过卡特尔则没有此选项）。

### 围捕行动
举报后，从第二天起三天一轮：

| 第几天 | 来客 | 收购 |
|---|---|---|
| 1 | 治安部医疗采购员："公民，我仅代表治安部公开采购对抗本地黑社会的药用品。" | 医疗品 |
| 2 | 治安部军需采购员："公民，我仅代表治安部公开采购对抗本地黑社会的军事补给。" | 食物、武器 |
| 3 | — | — |

- 两人买任何东西都 **−50%**；
- 各有固定 **500** 预算，**跨来访累计扣减**；预算归零时说"很好，仅代表治安部对慷慨捐赠的任何公民表示感谢。"并不再出现。

### 卡特尔被消灭
两人预算都花完时，获得 **卡特尔已被消灭** 标签，拒收立即停止。**一周后**，治安部后勤官上门：

> 公民，治安部在本地的围捕行动大获成功。
> 治安部后勤处感谢任何对本次行动的支持，
> 尤其是本地商业对后勤部的有偿赞助，
> 这些物资虽耗资不菲，但在物资紧俏的空间站，它们对治安部帮助良多。

治安部声望 **+50**，黑市声望 **−20**，治安部新增声望修正：

| 声望 | 修正 | 效果 |
|---|---|---|
| 120 | **后勤部的感谢**（"后勤部中会有些人记住部分商店的合作。"） | 治安部的任何采购多付 **15%** 小费 |

## 卡特尔网络声望

### 涨声望
和卡特尔的人做买卖（**买或卖都算**），按原版交易声望规则的 **4 倍**计入卡特尔网络：卡特尔商人、卡特尔快递员、同行，以及黑市游客（游客本身属于上层区，上层区声望照常，另外 4 倍计入卡特尔网络）。

### 声望修正

| 声望 | 名称 | 说明 | 效果 |
|---|---|---|---|
| −100 | **清算** | 卡特尔网络从不解雇任何人。 | 第二天早上原版的卡特尔杀手上门，游戏结束 |
| −60 | **联合抵制** | 其他黑市同行将不再光顾你的店铺。 | 黑市阵营的交易客人、以及专收违禁品的商人不再出现（剧情客人与电话订购的快递员除外） |
| −30 | **满腹狐疑** | 卡特尔对你的怀疑导致你的违禁品不再受人信任。 | 违禁品溢价减半（与枪匠许可证同理） |
| 0 | **公开交易** | 卡特尔的交易网络每周会吸引两名交易违禁品的商人。 | 每周随机两天出现卡特尔商人 |
| 25 | **三缄其口** | 顾客更不可能对你的商品质量提出异议。 | 虚标纯度、含致命物质等次日投诉的概率减半 |
| 50 | **生人莫入** | 小偷不会再光顾卡特尔统治的地盘。 | 每晚的保险服务换成免费的卡特尔保护（与化学家开局相同） |
| 75 | **供货网络** | 卡特尔网络会向你提供必要的原料，电话订购，价格从优。 | 解锁电话联系人"卡特尔网络"（见下） |
| 100 | **手眼通天** | 经过卡特尔的斡旋，现在任何针对你的调查都可以花钱了事。 | 刑罚一律为罚款，罚金 = 犯罪值，上限 1000；交罚款不扣治安部声望 |

负门槛修正在声望 **≤** 门槛时生效，可叠加（−60 时"满腹狐疑"也生效）。

## 卡特尔的人

| 人物 | 出现 | 交易 |
|---|---|---|
| **卡特尔商人** | 声望 ≥ 0，每周随机两天 | 收购任何违禁品（任何纯度），−5% 抽成；预算 250–300 + 天数 × 3 |
| **卡特尔快递员** | 声望 ≥ 75，电话订货次日 | 出售 20 瓶所选原料，批发 −33% |
| **同行** | 成员，每天 20%（至少隔 3 天） | 出售随机违禁品直到摆满外柜台，原价；10% 概率附带大型暗格 |
| **黑市游客** | 声望 ≥ 50，每天 20% 顶替一位普通买家 | 收购违禁的医疗品、麻醉品、武器、识别卡、物资箱；上层区预算 |

### 供货电话（2278）

> **卡特尔网络：**需要什么？
> [酸] [碱] [还原剂] [脂合剂] [酒精] [N溶液] [打错了]

选择药品："明天送到。最好不要让快递员记住你。"——次日快递员送来 20 瓶（原版供应商的成品瓶），冷却 3 天。选 [打错了]："……"

### 对话一览
- **同行**："我想你可能对它们感兴趣。" 成交时只有 "……"
- **黑市游客**："我就知道，下层区在混乱之中也容易滋生出特别的小店。""我是你们高层介绍来的……你懂的吧？" 每次成交："就这些吗？" 预算用完："无视法律的感觉真棒！"

## 兼容性与卸载

- 卡特尔网络是原版声望列表中的一个条目，"后勤部的感谢"是治安部的一个声望修正，二者随存档保存。卸载 mod 后它们留在存档里但不再有效果（面板中会显示原始文本键）。
- 若卸载时"生人莫入"给的卡特尔保护正处于开启状态，原版不会将其关闭。
- 所有改动通过 Harmony 补丁与 mod API 实现，不修改原版文件。
