# 电解食盐水 / Brine Electrolysis — 设计记录

参照现实中的氯碱工业：

> 盐矿 → 食盐水 →（电解）→ 氢氧化钠 + 氯气 + 氢气；氢气在氯气中燃烧 → 氯化氢 → 溶于水得盐酸

定位：后期批量自制酸碱。做出来的酸碱天生不带化学污染物和重金属，和前期的“矿石化学提纯原版酸碱”区分开。产物直接用原版的 `acid` 和 `base`，原版所有配方都能用。

## 气罐（已实现，`src/GasCanister.cs`，未在游戏里测试）

- **独立物品，不是原版液体容器**：原版约 90 处把“液体容器”统一处理（倒液、机器容器槽、水槽、排水口、买水顾客、净水片、移液枪 mod），做成液体容器会有很多漏洞。气罐用自己的标签（微升）分别记录氢气、氯气、氯化氢，原版液体系统碰不到它。
- 物品 `vce_gas_canister`，总容量 5 升（气体容易压缩），单价 25。
- 名字和图标随内容切换，优先级：有氯化氢 → 氯化氢罐；同时有氢气和氯气 → 氢氯混合气罐；只有一种 → 氢气罐 / 氯气罐；空 → 空气罐。图标 `vce_gas_canister`、`_h2`、`_cl2`、`_mix`、`_hcl`，16×32，1×2 格，由 `DrawElectrolysis.cs` 生成。
- 悬停逐行显示每种气体的量，再加“共 X / 5000 毫升，温度”。
- **混气**：把一个气罐拖到另一个上，所有气体并进被拖到的罐；装不下时按比例能装多少装多少，其余留在原罐。任何气体都能合并（同种气体也行）。温度按体积加权混合。
- **放气**：右键菜单原版的“切换”按钮在气罐上显示为“放气”，点了清空全部气体。只有氯化氢能倒出（溶进水里），其他气体只能放掉。
- **温度**：气罐有自己的温度（用和液体容器同名的标签，加热板能直接显示），每秒向 26°C 冷却温差的 0.4%，比液体慢很多。
- **获取**：电解机自带两个；退休化学家每次来店有 20% 的概率卖一个空罐。
- 调试按钮：Gas: empty canister / full hydrogen canister / full chlorine canister / hydrogen + chlorine canister。

- 图标 `art/salt/vce_electrolyzer.png`，48×48，3×3 格，和原版四台化学机器同尺寸、同配色。顶上两个出气口：黄绿色出氯气，红色出氢气，颜色对应气罐。
- 原版机器还有放了容器的 `_b` 变体，等机器的槽位定下来再画。

**界面（方向已定）**

照原版蒸发器的结构（`MachineEvaporator`：电池槽、模组格、容器槽、产物槽、便签槽），从左到右：

| 电池组 | 模组格 | 液体容器 | 连线 | 产物 A / 产物 B（上下排列） | 便签 |

- 电池组槽：`MachineHelper.SetupBatterySlot`，和蒸发器一样每个周期从电池扣电。
- 液体容器槽：只收原版液体容器（盐水在这里电解，碱留在这个容器里）。
- 产物 A、产物 B：只收气罐。
- 连线：液体容器槽和产物槽之间放一块自绘的图（`SpritePixelElement` + 本 mod 贴图），一条红线通向产物 A，一条蓝线通向产物 B。
- 悬停提示：连线元素实现原版的 `TooltipListener` 接口（原版悬停提示就是按鼠标位置找这个接口），悬停时显示“产物 A：氯气”“产物 B：氢气”这类说明。

**机器属性（已定）**：照原版含义，原版模组装上去效果和别的机器一致。

| 属性 | 作用 | 取法 |
|---|---|---|
| 性能 | 电解速度：每周期处理的食盐 ×(1 + 性能%/100)，最低 0 | `MachineryHelper.GetCurrentPerformanceBonus`，同蒸发器 |
| 效率 | 降低耗电 | 原版自动处理（`ModuleHelper.ApplyModifiedPower` 按效率扣减 `machinery_drawn_power`） |
| 质量 | 产物多少：质量 −100 → 产物 ×0.5，0 → ×1.0，+100 → ×1.5，中间线性；超出 ±100 按 ±100 算 | `MachineryHelper.GetCurrentQualityBonus` |

质量倍率作用在全部产物上（碱、氢气、氯气），消耗的食盐和水不变。

**运行（已定）**
- 和原版蒸发器一样，每晚结算一个周期（`onCycleEndSlotItemFunc`，在夜间服务里对所有物品各调用一次）。
- 耗电：默认每晚 24（`MachineryHelper.InitMachinery(machine, 24)`；蒸发器是 6）。电池电量不够这一晚就不运行。
- 处理量：默认每晚处理 3 块盐矿的食盐量，即 240 mL 食盐，再乘性能倍率。
- 运行条件：液体容器里至少有水，并且有食盐。
- 耗水：每电解 1 mL 食盐消耗 0.3 mL 水（现实中 2NaCl + 2H₂O → 2NaOH + Cl₂ + H₂，按质量约 117 克盐耗 36 克水）。水不够时按剩下的水能电解多少就电解多少，水用完就停。每晚 240 mL 食盐约耗 72 mL 水。不做溶解度限制。

**电解比例（已定）**：1 mL 食盐 + 0.3 mL 水 → 1 mL 碱 + 0.5 mL 氢气 + 0.5 mL 氯气（再乘质量倍率）。两种气体合成后得到 1 mL 酸。按此一块盐矿约出 80 mL 碱、80 mL 酸，6 块（90 元）约 480 mL 碱 + 480 mL 酸，约两份原版化学用品的量，而且是纯的。

**产物槽（已定）**：产物 A = 氢气（红线），产物 B = 氯气（蓝线）。

**碱的纯度**：只要水够、气罐没满，每晚都会继续电解，食盐最终会全部转化，不需要专门的“分离剩盐”步骤。中途停下时没电解完的食盐会留在碱里。盐矿带进来的杂质：物理污染物（颗粒 100）和矿物质（颗粒 30）都比净水滤芯的孔径（22）大，过滤一次就能去掉；多余的水可以用蒸发器蒸掉。

**获取（已定）**
- 杰克逊博士的商店出售电解机（用 `ModHook.OnPlaceInventorInventoryItemEarly`，和进阶化学手册同一个入口，常规和特殊进货都会触发；原版的发明家加价、事件价格照样生效）。
- 售价 400：原版化学机器是搅拌机 200、加热板 250、蒸发器 300、化学制剂成型机 300，电解机按同类的蒸发器 / 成型机再贵 100。
- 出现概率照杰克逊卖储物舱、机器舱、充电器的规则：玩家还没有电解机时每次进货都卖一台；已经有了，每次只有 25% 的概率出现。（原版杰克逊不卖化学机器，那几台只来自化学家开局和“退休化学家”人脉。）
- 卖出来的电解机，产物 A、产物 B 两个槽里各自带一个空气罐。注意：原版 `DirectoryMaster.Item` 会把新建物品里的子物品全部删掉，所以气罐要在摆上货架时再放进槽位，不能在物品工厂里放。

## 合成盐酸（已实现，`src/GasCanister.cs`，未在游戏里测试）

实现要点：反应速度每秒 10%、最少 1000 微升（同本 mod 较快的水解、玻璃固化）；加热板补丁（`MachineHeatingPlate.HeatingPlate`）让容器槽也收气罐，并按原版加热公式给气罐升温；不做氯爆鸣气爆炸。

不做单独的机器，用气罐和原版加热板手动完成：

1. **混气**：把一个气罐拖到另一个气罐上，两罐气体合进被拖到的那个罐，拖过去的罐变空（用原版物品的“拖到另一物品上”机制，倒水也是这样实现的）。气罐要从“只装一种气体”改成可以装混合气体。
2. **加热**：把混合气罐放到原版加热板上。需要补丁：加热板的容器槽也收气罐；原版按液体体积加热，气罐体积为 0 会被跳过，要让气罐也能升温。气罐有自己的温度，离开加热板后慢慢冷却。
3. **反应**：气罐温度 ≥ 120°C 时，每秒把一部分氢气和氯气转化成氯化氢：0.5 mL 氢气 + 0.5 mL 氯气 → 1 mL 氯化氢（现实 H₂ + Cl₂ → 2HCl）。没装模组的加热板最高 99°C，至少要 1 个化学模组。
4. **溶解**：把装氯化氢的气罐拖到液体容器上：容器里要有水，1 mL 氯化氢 → 1 mL 原版“酸”，水不减少（水只是溶剂）。**溶解度上限 40%**：酸占容器液体总量 40% 后不再溶解，多出的氯化氢留在罐里。

   - 倒的时候先算这一次最多能溶多少：除酸以外的液体总量记作“其他”，酸上限 = 其他 × 2/3（酸 ÷ (其他 + 酸) = 40%）；能溶的量 = min(酸上限 − 已有的酸, 罐里的氯化氢, 容器剩余容量)。例：500 mL 纯水最多溶 333 mL 酸。
   - 容器里没有水、或已经到 40%，一点都不倒。溶不进去的氯化氢留在罐里，不进入容器、不浪费。
   - 需要低浓度时，先做 40% 浓盐酸，再用原版滴管、量筒取用兑水。
   - 容器里有碱时，原版的酸碱中和会把倒进去的酸中和掉（手册里要提醒别往刚电解完的碱里倒）。

全线合计：1 mL 食盐 + 0.3 mL 水 → 1 mL 碱 + 1 mL 酸。

**气罐图（已画）**：`vce_gas_canister_mix.png`（氢氯各半，上红下黄绿）、`vce_gas_canister_hcl.png`（氯化氢，白色色环）。

**气罐颜色**：按密度上下分色。分子量氢气 2 < 氯化氢 36.5 < 氯气 71，所以混合气罐上半截是氢气的红色，下半截是氯气的黄绿色。氯化氢是无色气体，用白色 / 浅灰色色环，和空罐的灰色区分。（现实中气体会混匀不分层，这里只为好认。）
