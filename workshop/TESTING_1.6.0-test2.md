# 原版化学扩展 1.6.0-test2 测试说明

这是测试版，新内容还没在游戏里完整跑过，可能有 bug。谢谢帮忙测试！

## 安装

1. 把压缩包里的 `vanilla_chem_ext` 文件夹整个放进游戏的 `Mods` 文件夹，放好后应该是：
   `…\Probably Stolen\Mods\vanilla_chem_ext\VanillaChemExt.dll`
2. 如果订阅了创意工坊上的“原版化学扩展”，测试期间请先取消订阅或在游戏里禁用，否则两份会冲突。
3. 建议新开一个存档测试。测试版的物品以后可能会改，旧存档里的测试物品可能出问题。
4. 从 test1 升级：先删掉 `Mods` 里旧的 `vanilla_chem_ext` 文件夹，再放进新的。

## test2 修复

- 得了辐射病后，右键免疫宁无法使用。原因是原版只允许“哨兵”开局的玩家注射免疫宁；现在只要有辐射病就能用。真品每支缓解 5%；过期或假货打了没效果，会有提示。哨兵开局的玩家照旧。

## 这一版新增

**空心灯 / 失能剂**（已经在 1.5.0 里）：实验室辣椒，提纯成合法的失能剂，卖给上层区和治安部能冲减罪名和调查进度。

**电解食盐水（新）**：整条线是
盐矿石 → 搅拌机打碎得到食盐 → 加水做成盐水 → 电解机每晚电解，碱留在容器里，氢气、氯气进气罐 → 把两罐气体混到一起 → 放到加热板上烧到 120°C 生成氯化氢 → 拖到有水的容器上溶成盐酸。

- 盐矿石：给 GP 矿业打电话订购（6 块 / 12 块）。
- 电解机：杰克逊博士出售，自带两个空气罐。
- 气罐：右键可以“放气”；退休化学家偶尔也卖。
- 详细步骤在进阶化学手册的“电解食盐水笔记”一章。化学家开局会直接送一本手册。

## 快速测试（调试面板 → Modding 分类）

- **Salt: 3 salt ores**：3 块盐矿石。
- **Electrolysis: electrolyzer + battery + brine**：一台装好电池和两个空罐的电解机，加一瓶盐水（160 毫升食盐 + 100 毫升水）。
- **Electrolysis: run one night**：让所有电解机立刻跑一晚，不用睡觉。
- **Gas: hydrogen + chlorine canister**：一罐氢气、氯气各半的混合气，直接拿去加热板测试。
- **Gas: empty / full hydrogen / full chlorine canister**：各种气罐。
- **Chem: advanced chemistry handbook**：进阶化学手册。

## 请重点看看

1. 电解机界面：电池、盐水、红蓝连线、产物 A / B 的布局是否正常；鼠标放在连线上有没有提示。
2. 电解机的图标会不会随着放进 / 拿出盐水容器和气罐而变化（一共 8 种样子）。
3. 从杰克逊那里买下的电解机，里面送的两个气罐能不能拿出来。
4. 盐水放进去跑一晚后：容器里的食盐和水变少、出现碱，两个气罐里各有氢气、氯气。
5. 把一个气罐拖到另一个上能不能混气；右键菜单里有没有“放气”。
6. 混合气罐能不能放到加热板上，温度会不会升到 120°C 以上，罐子会不会变成氯化氢罐。
7. 氯化氢罐拖到有水的容器上，能不能变成盐酸，到 40% 时会不会停。
8. GP 矿业电话菜单里有没有盐矿选项，第二天快递员送的是不是盐矿石。
9. 得了辐射病后（调试面板里有 Nuclear: radiation +5%），右键免疫宁能不能注射，辐射病会不会减少。
