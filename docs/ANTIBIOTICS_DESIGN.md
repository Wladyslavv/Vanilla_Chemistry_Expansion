# 抗生素、菌种选育与抗药性

设计文档。状态：设计完成，尚未实现。最后更新：2026-11-13。

---

## 1. 概览

玩家培养**枝顶孢霉菌**，发酵产出**头孢菌素 C**，压成**抗生素片**作为医疗品出售。

整条链的核心玩法是**育种**：菌种带五项可见性状，繁育时会突变，玩家挑好的留种、用化学药品定向诱变，逐步养出高产菌株。制约来自**抗药性**：同一个基因组卖得太多就会失效，必须换基因组。

产线：

```
冷冻菌种 ──双击──> 菌种（带「育种」标签）
                      │ 放入发酵罐（被消耗）
                      ▼
              下一代菌种 ×4 / 2 晚
                      │ 搅拌机打碎
                      ▼
          头孢菌素 C + 蛋白质 ──化学成型机──> 抗生素片 ──> 医疗品买家
```

## 2. 物品

贴图在 `art/ferment/`。

| 物品 | 尺寸 | 贴图 | 说明 |
|---|---|---|---|
| 菌种 | 1×1（16×16） | `vce_strain` | 培养皿，琥珀色琼脂上的奶白菌落 |
| 冷冻菌种 | 3×3（48×48） | `vce_strain_frozen` | 低温罐，开窗可见冻存管与霜花 |
| 抗生素片 | 1×1（16×16） | `vce_antibiotic` | 圆形刻痕药片 |
| 发酵罐 | 3×4（48×64） | `vce_fermenter` | 和原版水培机同尺寸、同透视 |

菌种定为枝顶孢霉菌（*Acremonium chrysogenum*），现实中产头孢菌素 C 的就是它。

### 2.1 菌种

- 可以放进**发酵罐**。
- 放在**冰箱**里过夜，**冰箱空间够**时变成**冷冻菌种**（1×1 → 3×3）。原版冰箱的冷冻区是 3×2，每次扩容加一行（最多 3×9），所以**至少要扩容一次**，并且冷冻区里腾空才放得下；放不下时菌种保持原样。这是有意的门槛，写在手册里。
- 可以用**搅拌机**打碎，产出液体**头孢菌素 C**。

### 2.2 冷冻菌种

- **保留基因组和性状**，**双击**产生一个基因组、性状完全相同的菌种（无限次接种，对应现实的主种子库）。
- 这样产出的菌种带 **「育种」标签**：**打碎只出 1 mL 蛋白质**，没有头孢菌素 C。
  - 所以冷冻罐只能用来接种、不能直接变现，发酵罐是产线上绕不过去的一环。
  - 发酵罐收获的菌种**不带**这个标签，可以正常打碎。

### 2.3 头孢菌素 C（液体）

每一份都带着**纯度**和**基因组**两项信息，基因组借此跟随产品一路到药片。

- **纯度混合**：按液体量**加权平均**。
- **基因组混合**：整份**变成「生物废液」**（普通废液，不做特别设置）。
  - 混不同基因组不是稀释，是直接报废，所以“兑一点新菌洗白耐药批次”走不通。
  - 玩家必须把每一批严格分开。
- 还带一个**隐藏的萃取目标标签**，见 §4.2。

### 2.4 抗生素片

- 只打**医疗品**标签，由原版现有的医疗品买家消化，不另做专属顾客，也不做疾病系统。
- 基础价 **100**（标准性状），每 5 mL 头孢菌素 C 压一片。
- 纯度分三档，见 §7.2。

## 3. 发酵罐

### 3.1 界面

照原版蒸发器／本 mod 电解机的结构，从左到右：

| 电池组 | 模组格 | 输入 | 菌种输入 | 产物输出 | 说明书 |

- **电池组**：和电解机一样，**每晚**从电池扣电（`MachineHelper.SetupBatterySlot`）。
- **模组格**：通用模组（`MachineHelper.SetupModuleBay`，水培机的模组格形状）。
- **输入**：槽里固定放一个**原版牲畜饲料分配器**（`MachineFeedDispenser`），**不能取出、不能移动**。玩家往分配器里装料，发酵罐从中扣热量。
- **菌种输入**：放菌种。**投入的菌种会被消耗**，一轮结束后不留亲本，产出的全是下一代。
- **产物输出**：和原版水培机一样的输出网格 `new GameGridInventory(9, 6)`，9×6＝**54 格**，只出不进。菌种 1×1，所以一轮最多 54 个。
- **说明书**：和其他机器一样的便签槽（`MachineHelper.SetupManualSlot`）。

### 3.2 生产周期：批次制

- **一轮 = 2 晚**（标准性状），轮末一次吐出 **4 个**菌种。
- 轮长 = `round(2 ÷ (1 + 0.1 × 生长速度))`，**最短 1 晚**。
  - 初始 ±2.0 的范围内只有 −2.0 会拖到 3 晚，其余都是 2 晚；
  - 要压到 1 晚，生长速度得育到 **+3.4** 以上（性状无上限），这是育种的一个长期突破点。

### 3.3 耗电与耗料

- **耗电 12 点，按晚计**（不按轮计），所以缩短轮长不省电，只是每晚产出更多。
- **耗料按晚计**，标准 **50 kcal／晚**，按菌种的碳源利用效率浮动。
- 饲料分配器的原版机制：往里放食物会**销毁食物**、把它的 `CALORIE_VALUE_TAG` 累加到 `STORED_KCAL_TAG` 上，**上限 40000 kcal**（`MachineFeedDispenser.TryBlendItem`）。它还按肉／其他／颗粒料分桶记账，我们只读总量。

### 3.4 模组效果：三项属性都只减耗电

- **效率、性能、质量三项的加成直接相加**，得到耗电减少的百分比，三项各自不再有别的作用。
  - 例：10 + 10 + 20 = −40% 耗电，即 12 × 0.6 = 7.2 点。
- **下限为 0，不能为负**：`耗电 = max(0, 12 × (1 − 三项之和 ÷ 100))`。堆满模组做到完全不耗电是允许的。
- 对应原版标签：`TOTAL_PERCENTAGE_POWER_BONUS_INT`（效率）、`TOTAL_PERCENTAGE_PERFORMANCE_BONUS_INT`（性能）、`TOTAL_PERCENTAGE_QUALITY_BONUS_INT`（质量）。
- 参考：原版“系统效率模组”单个给 +16 效率，“系统质量模组”给 +8 质量。

### 3.5 售卖

- 价格 **400**。
- 进**杰克逊博士**和**退休化学家**的商店池，和电解机同一套挂法（`ModHook.OnPlaceInventorInventory` + `CreateRetiredChemist` 的 Postfix）。

## 4. 菌种的性状

| 属性 | 作用 |
|---|---|
| 基因组 | **只**决定抗药性归属，不影响任何其他属性 |
| 纯度 | 每 1.0 点使抗生素片**基础价值 +5**（标准 0 → 基础价 100） |
| 产量 | 每 1.0 点**产量 +10%** |
| 生长速度 | 每 1.0 点**每日生长速度 +10%** |
| 碳源利用效率 | 每日耗热：0 点为 **50 千卡**，每 1.0 点 **−5 千卡** |
| 萃取目标 | 三态：**液相 / 菌体表面 / 菌丝胞内** |

六项**全部直接显示**在物品上。

- **精度**：四项数值性状以 **0.1** 为最小步长（纯度 1.7、产量 −0.4 这样），界面显示一位小数。上表按 1.0 点折算，每 0.1 点即其 1/10。
- **产量和生长速度的结果四舍五入取整**（个数、晚数都是整数）；纯度和碳源利用效率连续生效。
- **性状没有上限**，可以一路往上叠。两处例外：
  - 碳源利用效率的每日耗热**可以到 0，但不能为负**；
  - 产量受输出槽封顶（54 格），不过以 4 个为基数要到产量 +125 才碰到，实际上是名义上限。

### 4.1 基因组

- **12 位**，每位 4 种字母，照 DNA 用 **A / T / C / G**（如 `ATCGATCGATCG`）。
- 共 4¹² ≈ 1677 万种组合。

### 4.2 萃取目标

头孢菌素 C 带一个**隐藏的萃取目标标签**，跟着液体走。压片时按该标签在原料里的占比判定：

| 萃取目标 | 占比 > 50% 时给抗生素片加的标签 | 原版标签名 |
|---|---|---|
| 液相 | 无效果 | — |
| 菌体表面 | 毒药 + **二级违禁品** | `POISON`，`contrabandMarkupMid` +70% |
| 菌丝胞内 | 麻醉品 + 烟酒类 + **一级违禁品** | `NARCOTIC`、`SUBSTANCE`，`contrabandMarkupLow` +35% |

原版词条是**烟酒类（Substance）**；毒药 = Poison，麻醉品 = Narcotic。

这两条分支实际上比医疗品卖得更贵，是“更赚但吃警察风险”的另一条路线，**不是惩罚**。

### 4.3 纯度性状与液体纯度是两套东西

性状纯度只动基础价值；抗生素片的三档分级（§7.2）由液体里蛋白质的占比决定。两者同名但互不影响。

## 5. 菌种的获得

**来源**：**退休化学家**和**退休农夫**各有 **20%** 概率卖一个菌种。

两人的到店日由原版 `StoreClientManager` 固定：

| 商人 | 到店日 | 解锁条件 |
|---|---|---|
| 退休化学家 | `dayCounter % 7 == 2` | 化学家开局，或买下人际网络升级 |
| 退休农夫 | `dayCounter % 7 == 5` | 农夫开局，或买下人际网络升级 |

所以一周最多两次机会。

**初始属性**（任何途径“获得”的菌种都按这套生成；冷冻罐接种出的和发酵罐收获的不算，它们是继承）：

- **萃取目标固定为液相**，所以菌体表面／菌丝胞内那两条违禁品路线只能自己诱变出来。
- 其他四项（纯度、产量、生长速度、碳源利用效率）在 **−2.0 ~ +2.0** 之间随机、步长 0.1，但**四项之和必须为 0**。
- **基因组完全随机**。

买来的菌种因此永远是“零和特化”而不是变强，想超过 0 只能靠育种。满足约束的组合共 45961 种，全 0 的标准菌种概率只有 1/45961，所以商人卖的基本都是 `产量 +1.3 / 纯度 −0.7 / 速度 +0.2 / 碳源 −0.8` 这样的小数；单项分布很平，某一项达到 +1.5 以上的概率约 12%。

## 6. 繁育与突变

### 6.1 繁育与退化

- 冷冻菌种**保真**：双击出的菌种性状与冻存时完全一致。
- **退化发生在繁育出的下一代菌种上**：发酵罐产出的菌种相对亲本掷一次自然突变，**期望为负**。
- 所以玩家要在“每次都回冷冻罐取种、性状不掉”和“直接拿收获的菌种接着种、省事但一代代变差”之间选。

### 6.2 自然突变（繁育时发生）

- **5%** 概率改变基因组的 **1~3 个**基因。
- **30%** 概率改变数值性状，变动**总和范围 −2 ~ +1、期望为负**。

### 6.3 特殊突变（定向诱变）

玩家把**液体容器拖放到菌种上**，消耗液体、保留容器。生效要同时满足三个条件：

1. 液体量为 **4.5 ~ 5.5 mL**；
2. **含量最大的液体**是会引起突变的液体；
3. **含量最大的液体纯度 ≥ 90%**。

| 液体 | 物品 id | 效果 |
|---|---|---|
| 酸、碱 | `liquid_acid`、`liquid_base` | 数值性状变动总和 **−5 ~ +5**，期望 **0** |
| 芬太 | `liquid_fanta` | 总和 **−10 ~ +10**，期望 **0** |
| N-甲基碱 | `liquid_n_methylol_base` | 同上 |
| 乙酸 | `liquid_acetic_acid`（本 mod） | 同上 |
| 乙酸乙酯 | `liquid_ethyl_acetate`（本 mod） | 同上 |
| 梦帽菇萃取液 | `liquid_dream_cap_extract` | 总和 **−2 ~ +4**，**期望为正** |
| 梦魇帽菇萃取液 | `liquid_nightmare_extract` | **25%** 概率随机改变**萃取目标** |
| 梦魔菌毒素 | `liquid_dream_toxin`（本 mod） | 每次改变基因组的 **1~2 个**基因 |
| 钚 | `liquid_plutonium`（本 mod） | 总和 **−100 ~ +100**，期望 **+5** |

- **变动总和如何分配**：**随机**摊到各项数值性状上，且每项的变动幅度不超过总和允许的范围（总和 −5~+5 时单项也只能在 −5~+5 之间动）。
- **条件不满足时**（液体量不对、纯度不够、最大成分不是诱变液体）：**液体照样消耗**，并引起一次总和 **−2 ~ 0** 的突变。乱倒东西是纯亏。
- **突变不会致死。**

梦魔菌毒素是主动更换基因组、规避抗药性的正途——用自家的招牌产品去换菌种身份。

## 7. 产出与定价

### 7.1 产出

标准性状下，一个菌种每两天产出 4 个菌种，即**每天 2 个可供加工**（前提是从冷冻罐取种，4 个全部拿去打碎）。

| 符号 | 含义 | 取值 |
|---|---|---|
| X | 每个菌种打碎出的液体 | 头孢菌素 C **27 mL** + 蛋白质 **3 mL** ＝ 共 30 mL |
| Y | 每片抗生素所需液体 | **5 mL** |
| Z | 抗生素片基础价 | **100** |

- 每个菌种出 6 片，每天 12 片；每批（两晚）120 mL、24 片。
- 标准菌种自带的蛋白质占总量 1/10，使不加工时纯度**恰好 90%**，正好压在药用级下限（原版判定是 `>= 90.0`）。
- 不加工直接压片 → 药用级 → 实收 90，**每日 12 × 90 = 1080**。

### 7.2 抗生素片的纯度分级

原版化学品分七档（+135 / +85 / +40 / 0 / −45…），抗生素**只分三档**：

| 纯度 | 效果 | 实收（基础价 100） |
|---|---|---|
| 实验室纯（≥99%） | +0% | 100 |
| 药用级（≥90%） | −10% | 90 |
| 其他（<90%） | **非卖品，不能出售** | — |

低于 90% 不是贱卖，是**直接不能卖**，所以不合格批次是纯粹的损失。现实里抗生素也确实有严格的纯度标准。

把蛋白质滤掉（酸碱凝聚 + 过滤，和快克因那条链一样）之后收益恰好相等：

| | 每天液体 | 片数 | 单价 | 每日 |
|---|---|---|---|---|
| 不提纯（药用级） | 60 mL | 12 | 90 | 1080 |
| 提纯（实验室纯） | 54 mL | 10.8 | 100 | 1080 |

蛋白质占 1/10、药用级罚 10%，正好抵消。**提纯买的是容错而不是利润**：标准菌种卡在 90% 的边缘上，加工中混进任何一点水或残渣都会掉到 90% 以下变成非卖品。

### 7.3 参考值 α：原版梦帽菇 → 梦尘

0.6α 是定价的锚。数字全部取自原版代码：

| 环节 | 数值 | 出处 |
|---|---|---|
| 水培机进度 | 每晚 +8 | `MachineHydroponic`：`InitProgressTypeMachine(…, 8)` |
| 梦帽菇所需进度 / 收获数 | 28 / 8 | `PlantList`：`PlantDefinition("dream_cap_seed", …, 28, 8)` |
| 一轮 | 4 晚 → 8 个大梦帽菇 | 28 ÷ 8 = 3.5 → 4 晚；满健康时全是大的 |
| 每个大梦帽菇的菇糊 | 27.333 ×(75 ÷ 32.5)≈ 63 mL | `SetDreamCapComposition(item, 75f)` |
| 性状额外注入 | +2 mL | `Production("dream_cap_mush", 2f, …)`，rank 1 |
| 菇糊 → 萃取液 | 最高 50% | `HandleDreamCapMushReaction`：酒精 ≥5 倍时系数 0.5 |
| 梦尘配方 | 2000 µL ＝ 2 mL／片 | `ChemFinisherRecipe`：`requiredVolume = 2000` |
| 梦尘基础价 | 18 | `MedsItemDirectory.DreamDust` |
| 实验室纯 / 违禁品 2 级 | +135% / +70% | `ItemConditionList.CreateLabPure`、`contrabandMarkupMid` |

- 每轮菇糊 8 × 65 ≈ 520 mL → 萃取液 260 mL → 梦尘 130 片 → 每天 32.5 片
- 单价 18 ×(1 +(135+70)÷100)≈ 55
- **α ≈ 32.5 × 55 ≈ 1800／天**，抗生素的 1080／天即 **0.6α**

α 依赖的前提，任何一条改了都要重算：满健康的大梦帽菇、50% 萃取率、梦尘达到实验室纯、违禁品 2 级溢价。抗生素只有医疗品标签，没有违禁品溢价。

## 8. 抗药性

抗药性**针对基因组**。售卖已产生抗药性的基因组时受到价格减益。

### 8.1 减益与规避

- **减益上限：售价 −50%。**
- 规避靠基因组差异：差异 ≥ **30%** 完全免疫，30% 以内**线性衰减**——减益倍率 = 1 − 差异比例 ÷ 30%。
- 12 位基因组 × 30% = 3.6，所以**差 4 位及以上完全免疫**，共 5 档：

| 不同的位数 | 差异比例 | 减益倍率 | 实际售价变化 |
|---|---|---|---|
| 0 | 0% | 100% | −50% |
| 1 | 8.3% | 约 72% | 约 −36% |
| 2 | 16.7% | 约 44% | 约 −22% |
| 3 | 25% | 约 17% | 约 −8% |
| ≥ 4 | ≥ 33.3% | 0 | 无 |

### 8.2 销售额的累计与衰减

- 计的是**累计销售额**，**固定计在卖出时的那一组基因组上**：每个基因组一条记录，各自累计、各自衰减、各自判定。
- 已耐药记录的减益按上面的线性衰减波及相似基因组，但**不会**把销售额并过去。
- **基础衰减：每天 500。**
- 某一天没有卖出这个基因组，它的每日衰减**再加 200**，逐日累加，直到再次卖出；卖出当天重置回 500。
- **衰减上限 2000/天**（连续约 8 天不卖到顶）。

| 连续未卖出天数 | 当天衰减 |
|---|---|
| 0（当天有卖） | 500 |
| 1 | 700 |
| 2 | 900 |
| 3 | 1100 |
| ≥ 8 | 2000（封顶） |

效果：停售后衰减越来越快，冷却一个基因组的代价随时间递减；持续高强度售卖则稳步逼近阈值。

### 8.3 抗药性怎么产生

- 阈值 **2000**：累计销售额在 2000 以下**永远不会**产生抗药性。
- 超过 2000 后每天判定一次：**每日概率 =（累计销售额 − 2000）÷ 10000**，上限 100%。

| 累计销售额 | 每日概率 | 期望触发天数 |
|---|---|---|
| ≤ 2000 | 0 | 永不 |
| 2500 | 5% | 20 天 |
| 3000 | 10% | 10 天 |
| 4000 | 20% | 5 天 |
| 5000 | 30% | 约 3.3 天 |
| 7000 | 50% | 2 天 |
| ≥ 12000 | 100% | 次日必定 |

### 8.4 效果与消失

- 一旦触发**立即吃满减益**（相似基因组按线性衰减折算），不是逐步变差。
- 把带减益的药摆上柜台时顾客会说一句专属台词：**“这个药最近不怎么管用。”**
  - 复用现有的“摆上柜台时说一句”机制（`src/RefusalLines.cs` 里卡特尔抵制用的就是它），本地化键例如 `antibiotic_resistance_line`。
- 该基因组的**累计销售额衰减到 0 时抗药性失效**。例如触发时累计 3000、之后完全不卖：

| 天 | 当天衰减 | 剩余累计 |
|---|---|---|
| 1 | 700 | 2300 |
| 2 | 900 | 1400 |
| 3 | 1100 | 300 |
| 4 | 1300 | 0 → 失效 |

## 10. 未定与后续扩展

**未定**

- **手册章节**：这条链要在进阶化学手册里加一章，等 coding 完成后再设计。

**明确不做**

- 疾病系统、每个菌种治什么病（抗生素只打医疗品标签即可）。
- 微生物污染／无菌要求。
- 头孢菌素 C 到药片之间的额外化学工序——保持“打碎 → 成型机”两步，让玩家专注育种。
- 生物废液的特殊性质。

**后续扩展（分期）**

- 第 1 期：一种抗生素的生产 + 抗药性（即本文档）。
- 第 2 期：菌种筛选、多个抗生素类别。
- 第 3 期：牲畜用药（原版牲畜疾病 `ANIMAL_DISEASED_TAG` 目前无药可治）与疫情事件（原版未使用的 `EventUnused.Outbreak` 框架）。

**备选方案：全站“抗生素饱和度”**

如果轮换几个菌种就能无限规避抗药性显得太轻松，可以在各基因组的记录之外再加一个**全站共用的计数**：

- 所有抗生素的销售额都计入这一个数，不分基因组，同样随时间衰减。
- 它**本身不产生减益**，只推高新抗药性出现的概率（或等效地压低各基因组的阈值）。
- 效果：轮换仍然有用，但“卖得越多，整体越容易出耐药”，无限扩产不再免费。
- 现实依据充分：耐药基因可以通过质粒**水平转移**在菌株之间传播，这正是现实中耐药性扩散的主要途径。
- 实现成本低：一个数值、一条衰减、一处概率修正，不触碰其他已定规则。

## 附：现实工艺要点（设计参考）

- 大多数抗生素的骨架来自发酵（霉菌：产黄青霉、顶头孢霉；放线菌：链霉菌）；很多成品是半合成（如由青霉素切出 6-APA 再接侧链）；也有全合成（喹诺酮、磺胺、利奈唑胺）。
- 工业发酵：单一菌株、严格无菌、补料分批，一批一批做；收获后菌丝灭活处理，不作为下一批种子。
- 菌种库：主种子库 → 工作种子库 → 每批取一管。工作种子用完回到主种子库重新扩增，不拿工作种子再扩增工作种子；尽量少传代，因为高产性状不稳定，“偷懒”的突变株长得更快，会挤掉高产株。
- 选育：诱变（紫外、X 射线、化学诱变剂，剂量杀死 90%～99%）→ 单菌落分离 → 大量筛选（最贵的环节）→ 复筛与稳定性检验 → 最好的作为下一轮亲本。青霉素产量由此提高了数千倍（起点是皮奥里亚市场一个发霉哈密瓜上的菌株）。
- 菌种来源：土壤等自然样品筛选（链霉素、红霉素、万古霉素）、偶然发现、保藏中心（ATCC、NRRL、CGMCC）、企业自有菌株（商业机密，有过菌种盗窃案）、基因组挖掘与不可培养菌培养（泰克霉素）。
- 青霉素工艺：含糖和蛋白质的培养基，两阶段（先长菌、后产药），糖一次给太多会抑制产药、需分次补糖；提取是过滤菌丝 → 酸化 → 乙酸乙酯萃取 → 碱性水溶液反萃 → 蒸干 → 结晶。
