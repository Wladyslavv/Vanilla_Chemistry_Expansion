# 溶质极性设计（为高效液相色谱仪准备）

给游戏里每一种液体成分定一个**极性值 P（0–100）**，以后色谱仪按它把混合物分开。P 越大越亲水、越“极性”。

## 定值规则

1. **溶解的小分子**：按现实对应物的辛醇/水分配系数 logP 计算，这也是真实反相色谱（C18 柱）里决定出峰顺序的量：
   **P = 60 − 12.5 × logP**，限制在 0–98，四舍五入。
   - logP = 0（亲水亲油一样）→ 60；logP = 4（很亲油）→ 10；logP = −3（很亲水）→ 98。
2. **离子、强酸强碱、盐**：logP 没有意义，直接定为 95–100。
3. **大分子**（蛋白质、淀粉、抗体）和**虚构物质**：手定，表里写明参照的现实物质。
4. **颗粒**：游戏里粒径 > 22 的成分（滤水器能滤掉的那些）不溶于流动相，**没有极性值**。设定为“进样前必须过滤，否则堵柱”，正好接上游戏现有的过滤机制。
5. **溶剂**：水、酒精、甲醇是溶剂，不是被分离的溶质，**没有极性值**。样品里带的这三种会随溶剂峰最先流出（死时间），不算分离结果。

## 流动相

- **只有甲醇是合格的分离溶剂**：色谱仪的溶剂瓶只接受甲醇，没有甲醇就不能运行。
- 水和酒精不能当流动相用。
- 甲醇的来源：工业酒精线里微生物产生的甲醇；植物质在 150°C 以上干馏，同时产出乙酸和甲醇。气罐里的氢气在加热板上加热到 150°C 以上，和空气里的二氧化碳生成甲醇蒸气（3 份氢气生成 1 份），拖到任意液体容器上冷凝成甲醇，不带水，纯度 100%。

## 色谱仪的运作（已实装，见 src/Hplc.cs）

界面从左到右：流动相容器、样品容器、色谱柱和 4 个收集槽、极性表、说明书。每秒：

1. 流动相要 99% 以上是甲醇才运行。运行时消耗甲醇：每分离 1 毫升溶质消耗 0.06 × (50 + 样品里最高的极性) 毫升，即 3–9 毫升。甲醇不够时按剩下的甲醇量减少这一秒的分离量；连每种溶质 1 微升都付不起时暂停，提示甲醇不足。极性表里显示分完整份样品预计要多少甲醇。
2. 样品里有颗粒就拒绝运行，提示先过滤。
3. 样品里的溶质按极性从低到高排序：
   - 不超过 4 种：每种一个收集槽，极性最低的在最下面的槽，往上依次升高。
   - 超过 4 种：在极性差最大的 3 处切开分成 4 组，极性相近的进同一个槽，4 个槽都有。
4. 每秒最多分离 5 毫升溶质。每种溶质按同样的比例减少，所以同时分完，中途不会换槽。
5. 每流出 1 毫升溶质，带出 1 毫升样品里的溶剂，按样品里水、酒精、甲醇的比例。
6. 应该收到东西的收集槽缺容器或放不下，或样品里没有溶剂了，就暂停。

极性表带滚动条，表头「名称」「极性」可以点击排序，再点一次反向。样品里没有溶质时列出游戏里全部溶质（名称、极性两列）；样品里有溶质时只列这些，多一列要去的槽号。表下方显示分完整份样品预计消耗的甲醇。

## 几个值得注意的分组

- **能分开的典型配对**（ΔP 大）：油脂 0 ↔ 咖啡因 61；可卡因游离碱 31 ↔ 盐酸快克粉 85；钚萃取物 10 ↔ 溶解的钚 96；辣酯 4 ↔ 辣椒素 22。
- **难分开的配对**（ΔP < 5，可以作为“需要更好的柱子 / 更长的运行时间”的玩法点）：
  - 乙酸 62 / 咖啡因 61
  - 甲苯 26 / 家畜类固醇 26 / 地西泮类 Synaprest 25
  - 梦帽菇萃取液 76 / 化学上相近的梦魇萃取液 84（ΔP 8，能分但不轻松）
  - 糖 98 / 头孢菌素 C 98 / 硝酸 98（极性端挤在一起）
- **离子全部挤在 95–100**：反相色谱本来就很难分离离子，这和现实一致。如果想让离子之间也能分，可以另做一种“离子交换柱”。
